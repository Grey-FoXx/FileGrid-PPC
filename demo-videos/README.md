# FileGrid demo videos

Fișierele MP4 sunt urmărite prin Git LFS, nu ca obiecte binare în istoricul Git normal.

- `FileGrid-poveste-montaj-final.mp4` — filmul original cu inserția FileGrid;
- `FileGrid-demo-aplicatie-final.mp4` — inserția aplicației;
- `FileGrid-demo-tehnic-extins-final.mp4` — observabilitate și trasabilitate extinsă.

După clonare sau pull:

```bash
git lfs install
git lfs pull
```
