# Verification limits

This is a hackathon prototype. Synthetic ML demonstrates plumbing, not operational accuracy. HTTP Basic over local TLS is prototype authentication. A locally generated certificate needs explicit browser trust. Application encryption key management is local, not enterprise KMS.

MVP PostgreSQL is a shared availability dependency. One-host volumes are not backups or HA. FTP is internal-only and accepts non-sensitive legacy diagnostics. Two-pass download verification increases latency. Full 10x isolation, >1GB resource measurements, FTPS, alerts, HA and backup restoration require the M3/M4 validation campaign.

Host initially lacks Docker socket access. A production build or unit-test pass does not prove Docker integration. Exact checks and remaining failures are recorded in progress documents.
