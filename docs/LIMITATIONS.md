# Known limitations after backend hardening

See BH02_06_REPORT.md for executed checks and precise benchmark scope. Earlier checkpoint reports remain historical evidence.

- PostgreSQL remains a single shared metadata dependency. Storage outage isolation and restart recovery do not provide HA, host-loss protection, synchronous replication, backup restore or horizontal scaling. These require a separate campaign.
- Admission bulkheads and category verification workers reserve bounded capacity, but CPU, JDBC, disk and networks are shared. Some storage operations still occur inside SQL transactions. A successful measured 10x workload is not a guarantee for arbitrary rates or payload sizes.
- Basic authentication is used over HTTPS with generated local accounts. No identity provider, session revocation or account-management UI. AES-GCM uses one persistent local key without KMS or rotation. Preserve the key, accounts, FTP certificate and storage volumes together; backup/restore is not yet verified.
- Runtime API uses a restricted MinIO object account; administrative credentials are confined to initialization/provisioning. MinIO Community is archived/source-only and built from the fixed source commit. S3 and SQL traffic remain plaintext on the private Docker data network; FTPS control and data require TLS 1.2 or newer.
- Personal document content is encrypted; filename/owner/application metadata in PostgreSQL is not encrypted. Owner/role checks and ciphertext probes are not a comprehensive penetration test or regulatory certification.
- Gateway and FTPS certificates expire after 30 days. Bootstrap preserves them across restarts and does not automatically renew them. Plan deliberate certificate renewal before expiry.
- Policies support category, attachmentType and sensitivity. Unsupported criteria fail validation. Changes apply on restart to new sessions; existing content is not migrated. Health/cost/performance-driven routing is not implemented.
- Download verifies content and then performs a second streaming read. This adds I/O and depends on immutable UUID keys/versions. Failure to acquire the second stream now returns a correctly framed error; failure after streaming starts can still interrupt transfer. Clients must verify SHA-256 and retry.
- Single-request content is limited to 10 MiB; drones use 8 MiB parts and a 20 GiB declared maximum. Native 1229 MiB transport used synthetic bytes. Docker isolation fixtures use 8 MiB+17 bytes for drones, not semantic video or a >1GB Docker benchmark. Browser downloads over 128 MiB require File System Access support.
- Session/orphan cleanup and lease races need further concurrent expiration/cancellation tests. This MinIO build rejects AWS AbortIncompleteMultipartUpload lifecycle rules; default stale-multipart cleanup timing was source-inspected, not elapsed-time tested.
- Meter sequence gaps are observed after a 60-second server-time grace. Gap counting assumes each meter begins at sequence 1, as the simulator does; onboarding an existing nonzero sequence baseline needs an explicit contract/configuration. A missing tail without any later sequence cannot be inferred. The simulator has durable replay but does not yet offer a complete configurable invalid/gap/outage scenario suite.
- Seven Prometheus business rules feed private Alertmanager and a token-protected internal webhook, persisted in SQL and structured logs. There is no public alert API, frontend alert panel, email/pager receiver or independent alert persistence during a PostgreSQL outage. Public additions require frontend coordination.
- Metrics count acknowledged payload bytes, not all physical network traffic. Histograms yield approximate quantiles; finite benchmark samples, warmup/background simulator and local hardware limit confidence, especially p99. Tracing is correlation through logs/SQL rather than a distributed tracing system.
- ML is synthetic, advisory, asynchronous and independently retryable. Cluster labels are local to one analysis; operational validation, global incident grouping and model lifecycle management remain open.
- GitHub Actions and remote publication of this hardening branch have not been verified in this session. Local generated secrets and raw runtime artifacts remain ignored. Never copy runtime secrets through Git.
